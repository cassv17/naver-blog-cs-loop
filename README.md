# 네이버 블로그 CS·이웃 루프

내 블로그에 새 글이 올라온 날, 자동으로 아래 일을 해 주는 Claude + ego lite 자동화입니다.

1. **댓글 답글**: 새 댓글에 짧게 답글을 답니다. 견적문의 댓글에는 안내 문구를 **비밀답글**로 답합니다.
2. **이웃 늘리기**: 키워드로 최근 글을 쓴 다른 블로거를 찾아 서로이웃을 신청하고 글에 짧은 댓글을 답니다.
3. **알림**: 사람이 직접 봐야 하는 댓글(불만·자재 질문 등)이 있으면 답하지 않고 Windows 알림으로 알려 줍니다.

---

## ⚠️ 먼저 읽어 주세요 — 최초 1회는 본인이 직접 로그인

이 자동화는 **비밀번호를 입력하지 않습니다.**
**ego lite 브라우저에서 본인 네이버 계정으로 최초 1회 직접 로그인**해 두어야 합니다. 한 번 로그인하면 이후에는 로그인이 유지됩니다.

- 로그인하는 곳은 일반 크롬이 아니라 **ego lite 브라우저의 프로필**입니다.
- 계정 하나당 프로필 하나를 쓰세요. 다른 자동화(카페 등)가 쓰는 프로필과 섞이면 댓글이 엉뚱한 계정으로 올라갈 수 있습니다.
- 로그인이 풀리거나 다른 계정으로 바뀌면 자동화는 **아무것도 등록하지 않고 멈춘 뒤** 로그인이 필요하다고 알립니다.

## 준비물

| 필요한 것 | 확인 방법 |
|---|---|
| Windows 10/11 (알림은 Windows 전용) | |
| Claude Code 데스크톱 앱 (예약 작업 사용) | 앱에 "Scheduled" 메뉴가 보이면 됩니다. |
| ego lite 브라우저 + `ego-browser` 명령 | 터미널에서 `ego-browser skill` 이 실행되면 됩니다. |
| Node.js 18 이상 (설치 마법사용) | 터미널에서 `node --version` |
| 본인 네이버 블로그 | |

## 설치 (약 10분)

1. 이 저장소를 내려받습니다.
   ```bash
   git clone <저장소 주소> naver-blog-cs-loop
   ```
2. 폴더 안의 **`setup.cmd`를 더블클릭**합니다. 질문에 답하면 `config.json`이 만들어집니다.
   - 블로그 아이디, 닉네임, 실행 시간
   - 견적문의 안내 문구 (레몬하우스 기본 문구 / 직접 입력)
   - **서로이웃 범위** (아래 참고)
3. ⚠️ **ego lite 브라우저의 해당 프로필에서 본인 네이버 계정으로 직접 로그인**합니다.
4. Claude Code에 `최초로그인_프롬프트.txt` 내용을 붙여넣습니다. 블로그 주인 계정으로 로그인됐는지 확인해 줍니다.
5. Claude Code에서 `예약작업_프롬프트.txt` 내용으로 매일 실행하는 예약 작업을 만듭니다. (실행 시간은 설치 때 정한 값입니다.)

> 이 폴더의 `config.json`, `처리기록.json`, `*_프롬프트.txt`는 개인 정보가 들어 있어 Git에 올라가지 않도록 막혀 있습니다(`.gitignore`).

## 서로이웃 범위 설정

설치할 때 한 번 정하고, 나중에 `setup.cmd --neighbor`(또는 `node setup.mjs --neighbor`)로 **언제든 다시 바꿀 수 있습니다.** `config.json`의 `neighbor` 항목을 직접 고쳐도 됩니다.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| 사용 여부 | 끄면 댓글 답글만 합니다. | 켬 |
| 신청 방식 | `서로이웃`(상대가 수락해야 맺어짐) / `이웃추가`(내가 일방적으로 구독) | 서로이웃 |
| 검색 키워드 | 이 키워드로 최근 글을 쓴 블로거를 찾습니다. 여러 개면 날마다 돌아가며 씁니다. | (직접 입력) |
| 대상 주제 | 예: "인테리어·리모델링 관련 글만". 비우면 검색 결과 전체. | 비움 |
| 제외 단어 | 제목·본문에 이 단어가 있으면 건너뜁니다. 예: 자동차, 광고 | 비움 |
| 글 최신성 | 최근 몇 시간 안에 올라온 글만 대상으로 할지 (1~72) | 24시간 |
| 하루 신청 인원 | 서로이웃 신청 최대 수 (1~50) | 10명 |
| 하루 외부 댓글 | 다른 블로그에 다는 댓글 최대 수 (1~50) | 10개 |

처음에는 **하루 10 이하**를 권장합니다. 같은 행동이 많이 반복되면 네이버 보호조치가 걸릴 수 있습니다.

## 처음 1주는 "승인 모드"

설치 후 7일 동안은 답글·댓글·신청 **초안을 표로 먼저 보여 주고, 사용자가 승인한 것만 등록**합니다. 톤이 마음에 들면 "자동으로 전환해 줘"라고 말해 주세요. 사용자가 말하기 전에는 자동 전환되지 않습니다.

## 안전장치

- 등록할 때마다 **블로그 주인 계정인지 확인**하고, 등록한 댓글의 닉네임이 내 닉네임이 아니면 즉시 전체 중단합니다.
- 동작 사이에 30~90초 무작위로 쉽니다.
- 캡차·보호조치·한도 메시지가 나오면 즉시 멈춥니다. **캡차는 풀지 않습니다.**
- 같은 문장의 댓글을 두 번 쓰지 않고, 이미 신청한 블로거에게 다시 신청하지 않습니다(`처리기록.json`).
- 내 글·댓글 삭제, 이웃 삭제, 설정 변경, 비밀번호 입력은 하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `setup.cmd` / `setup.mjs` | 설치 마법사 (서로이웃 범위 수정은 `--neighbor`) |
| `루프_지침.md` | Claude가 매 실행 때 읽고 따르는 작업 지침 |
| `알림.ps1` | Windows 알림 띄우기 |
| `templates/견적문의_레몬하우스.txt` | 견적문의 안내 문구 기본값 |
| `config.example.json` | 설정 파일 예시 (실제 설정은 `config.json`) |

## 문제 해결

| 증상 | 해결 |
|---|---|
| "ego lite에서 네이버 로그인 필요" 알림 | ego lite 해당 프로필에서 다시 로그인한 뒤 `최초로그인_프롬프트.txt`로 확인합니다. |
| 한글이 깨져 보임 | `setup.cmd`로 실행합니다(UTF-8로 바꿔 줍니다). |
| 예약 시간에 실행되지 않음 | Claude 앱이 켜져 있어야 합니다. 꺼져 있었다면 다음에 앱을 켤 때 실행됩니다. |
| 서로이웃 범위를 바꾸고 싶음 | `setup.cmd --neighbor` |

## 주의

- 이 저장소는 공개입니다. 견적문의 안내 문구(`templates/`)에는 회사 공개 대표번호와 공식 카페 주소만 들어 있고, 개인 계정 정보는 없습니다. 내 계정·고객 정보는 절대 커밋하지 마세요.
- 다른 블로거 정보가 들어 있는 `처리기록.json`은 절대 커밋하지 마세요.
